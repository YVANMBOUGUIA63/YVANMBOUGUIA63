# Présence des militaires en politique et croissance économique

Projet réalisé dans le cadre du cours d'économétrie de la croissance, M2 Économie du Développement, École d'économie CERDI, Université Clermont Auvergne.

## Description

Analyse de l'effet de la présence des militaires en politique sur la croissance économique pour 217 pays sur la période 1995-2023. L'étude utilise l'indice ICRG (International Country Risk Guide), procède aux diagnostics des moindres carrés ordinaires, puis corrige l'endogénéité par estimation en variables instrumentales.

## Contenu

- `rapport econometrie.pdf` : rapport complet du projet
- `base finale.xlsx` : base de données utilisée (format Excel)
